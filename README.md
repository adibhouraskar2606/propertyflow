# PropertyFlow

PropertyFlow is a cloud-based property management platform being built as a full-stack project.

The platform will support landlords, tenants, and maintenance professionals.

## Planned Technology Stack

### Frontend
- React
- TypeScript
- React Native

### Backend
- Java
- Kotlin
- Spring Boot

### Databases
- PostgreSQL
- DynamoDB

### Cloud
- AWS

### Infrastructure
- Docker
- Kubernetes
- Terraform

### CI/CD
- GitHub Actions

### Monitoring
- AWS CloudWatch
